## About SightScout

**SightScout** is a location-aware tourism discovery component that helps users find interesting places using natural-language search.

Users can search queries such as:

- `museums in Paris`
- `tourist attractions in Tokyo`
- `things to do in Paris`

SightScout understands the destination and the type of places being requested, then displays relevant nearby locations in an easy-to-browse interface.

## Features ✨

- 🌍 Location-aware destination detection
- 🔍 Natural-language tourism queries
- 🏛️ Museums, attractions, parks, zoos, aquariums and more
- 📍 Nearby places within a 5 km radius
- 🖼️ Images for attractions when available
- 📌 Address and location details
- 🗺️ Direct **View on Map** navigation
- ⚡ Fast, responsive card-based interface
- 🌙 Clean dark-themed UI

## How It Works

1. The user enters a natural-language tourism query.
2. SightScout identifies the destination and requested category.
3. Tourism places are fetched based on the destination's coordinates.
4. Results are enriched with relevant images where available.
5. Places are displayed as interactive cards with location information and map navigation.
